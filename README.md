## ⚙️ **Run Locally**

### Clone the project

```
git clone https://github.com/23f2002668/Portfolio.git
cd Portfolio
```

---

### Install dependencies
```
pip install -r requirements.txt
```

### Run the server
```
python app.py
```

### Portfolio opens at :
👉 [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
